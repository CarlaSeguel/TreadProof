# 01 — Problema

## Hipótesis inicial

Las empresas que solicitan la gestión de NFU necesitan reconstruir qué ocurrió con sus lotes y qué cantidad fue efectivamente valorizada. Cuando cada participante mantiene registros separados, puede ser difícil relacionar el retiro, la recepción y la evidencia de tratamiento.

## Dificultades que se busca abordar

- Registros y documentos dispersos entre empresa, punto de retiro, transportista y planta.
- Diferencias de peso entre etapas sin explicación trazable.
- Dificultad para identificar quién declaró o verificó cada dato.
- Riesgo de acreditar varias veces el mismo lote o material.
- Falta de una consulta clara de cantidades declaradas, recibidas y valorizadas.

## Validación pendiente

Conversar con posibles usuarios para conocer sus registros actuales, documentos disponibles, frecuencia de discrepancias y necesidades de consulta. Identificar al usuario principal y al eventual cliente pagador.

No se incluyen todavía cifras de mercado, clientes confirmados ni afirmaciones de cumplimiento normativo.
